个人、通知和订阅根据邮件头、发件地址和自定义规则自动归类。手动纠正时可以记住发件人，以后来自同一人的邮件会沿用该分类。

优先、置顶和本地归档独立于邮件分类。归档只改变本机显示；已读状态在真实账户模式下同步到服务器。

写邮件支持附件、抄送、密送与定时发件。定时任务需要 TeleMail 保持运行，错过的任务会在下次启动时执行。发送结果待确认时，请先核对服务商记录，避免重复发送。

演示模式不外发邮件。真实账户请按项目 README 配置服务器与授权环境变量后重启。OAuth2 使用你提供的有效访问令牌，当前版本不自动续期。
