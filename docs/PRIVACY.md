# 隐私与数据说明

TeleMail 是本地邮件客户端，没有项目自建邮件云服务或遥测上传接口。应用会连接用户配置的 IMAP/SMTP 和 OAuth 服务；它不是离线邮件服务。

## 保存的数据

本机保存账号连接设置、下载的邮件及附件、通讯录、过滤器、草稿、发送队列、偏好和诊断日志。Windows 使用当前用户的 DPAPI 保护已记住的登录；Linux 使用本机独立设备密钥和 AES-256-GCM。相同操作系统用户或管理员仍可能访问本机资料，这不等于硬件隔离。不要将用户资料目录提交到 Git。

Windows 配置通常位于用户的 Roaming AppData/maildesk，缓存位于 LocalAppData/maildesk；诊断日志位于 LocalAppData/TeleMail/logs。Linux 使用用户 XDG 配置/数据目录。演示模式使用独立资料目录。

## 网络与预览

远程邮件图片默认阻止。允许后，应用直接连接图片服务器，可能暴露 IP 和阅读时间。外部链接交给系统浏览器。OAuth 登录交给用户配置的服务商及客户端注册信息；本项目未提供统一经审核的 OAuth 注册。

PDF.js 和阅读资源随应用保存。活动 PDF 经绑定 127.0.0.1 的临时、随机地址在应用内读取，不上传云端；关闭后停止该地址。邮件 HTML 不运行脚本。PDF 页面脚本、XFA、宏和嵌入附件不执行。

## 删除与服务器操作

可在账号设置忘记凭据；移除账号连接不等于删除已下载邮件或草稿。清理缓存前应使用应用提供的核对和清理操作。

自动整理目前默认启用：把服务器收件箱里超过保留天数（默认 365 天）、未置顶的邮件移到垃圾箱。垃圾箱可能被服务商永久清空。请在连接真实邮箱后、同步和长期运行前检查该设置，尤其是企业保留场景。删除、移动、归档等操作可能同步至服务器。

稍后发送和回执均由本机及收件服务处理。发布者不应把测试结果描述成安全认证或服务商认证。
