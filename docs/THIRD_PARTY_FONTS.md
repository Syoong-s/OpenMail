- Name: Noto Sans CJK SC Regular, original OpenType font.
- Source: [official Noto CJK repository](https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese)
- License: SIL Open Font License 1.1; full upstream license included at `maildesk/desktop_assets/fonts/OFL.txt`.
- SHA-256: `2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`.
- Font bytes are unmodified. Copyright and font metadata remain embedded in the original file.
- The font is registered through Fontconfig only for the running TeleMail application. It is not installed into a system font directory.
