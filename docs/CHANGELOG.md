# 更新记录

## 0.55.0

- 应用改名为 TeleMail；更新界面、通知、页脚、启动器、发行包与 GitHub 自动发布名称，采用独立 TeleMail 数据路径、应用身份和环境变量；移除 Maildesk 路径/命令/安装包兼容。

- 修复 Linux 邮件/联系人富文本气泡按估算高度显示而留白或截断的问题；按实际正文适配，并消除 WebKit 缩放/复用保留的旧建议高度。邮件脚本继续禁用，表格、图片和品牌按钮样式保留。

- 使用本地 PDF.js 6.4.299 替换 Poppler，支持连续滚动、选择文字、搜索高亮、缩放与密码 PDF。
- 阅读资源离线分发，PDF 使用独立临时本机地址；邮件 HTML 的脚本限制保持原策略。
- Windows 运行库显式保留加密组件；Linux 包包含完整当前应用模块。
- 整理公开源码仓库：排除历史分析、个人运行数据和旧包；补充许可证、隐私、构建与对应源码说明。
- Windows 与 Linux 的 PDF 原生界面检查各 9 项通过。修正 15 项旧测试夹具问题后，两端完整后端测试各 320 项通过（各 2 项平台跳过）。发行附件 RELEASE_VERIFICATION.json 保存本次结果。
